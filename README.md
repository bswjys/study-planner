# 장신대 플래너

장신대 신학대학원 입학고사(2028학년도 대비)를 준비하는 **1~10회독 공부 계획 · 진도 관리** 웹앱입니다.
아이폰 사파리에서 열고 **홈 화면에 추가**하면 주소창 없는 단독 앱처럼 쓸 수 있어요.

## 쓰는 법 (아이폰)

1. 사파리에서 이 페이지를 엽니다 → https://bswjys.github.io/study-planner/
2. 하단 가운데 **공유** 버튼(□↑)을 누릅니다.
3. **홈 화면에 추가**를 선택합니다.
4. 홈 화면의 **장신대 플래너** 아이콘으로 실행하면 앱처럼 열립니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| **오늘** | D-day, 전체·현재 회독·이번 주 진행률, 오늘 분량 **공부량 조정 / 완료**, 이번 주 7일 현황(일~토, 캘린더와 같은 주 경계), 진도가 밀리면 **오늘부터 다시 맞추기** 카드 |
| **회독** | 목표 회독(1~10) 선택, 회독별 기간·진행률, 날짜별/권별 전체 일정 탐색과 체크 |
| **캘린더** | 월별 달력, 완료/미완료/오늘/예정 색 구분, 날짜 탭 → 그날 공부 (주일을 뺀 설정에서는 주일 휴식 표시) |
| **더보기** | **주일에도 공부하기** 토글, **오늘부터 다시 맞추기 / 원래대로 되돌리기**, JSON 백업·복원, 전체 초기화, 확장 탭 자리(논술 공부·운동 루틴), 학습 정보 |

- 체크는 누르는 즉시 진행률에 반영되고, **이 기기 브라우저(localStorage)에만** 저장됩니다. 서버로 보내지 않습니다.
- 기기를 바꿀 때는 더보기 → **JSON으로 내보내기**로 백업하고, 새 기기에서 **JSON 불러오기**로 복원하세요.

## 계획 계산 방식

- 공부 기간: **2026.11.23(월) ~ 2027.11.30(화)** — 주일(일요일)까지 넣으면 **373일**(기본값), 주일을 빼면 **320일**
- 범위: **66권(구약 39 · 신약 27) 3,009문항** — 삭제 3문항(요한복음 071 · 사도행전 045 · 로마서 031)은 범위에 두되 학습량에서 제외(실제 3,006문항)
- 목표 회독 `N`(기본 3)에 따라 학습일을 `N`개 회독으로 나누고, 각 회독에서 66권을 번호 순서대로 배분합니다.
  - 주일 포함 373일 · 3회독: 회독당 125 / 124 / 124일, 하루 약 24문항 (하루 22~26문항)
  - 주일 제외 320일 · 3회독: 회독당 107 / 107 / 106일, 하루 약 28문항 (하루 26~30문항)
  - 10회독: 회독당 37일(373일 기준), 하루 약 81문항
- 하루 경계는 책 경계에 가깝게(±3문항) 맞춰 `레위기 001~001` 같은 자투리가 생기지 않게 했습니다.
- 회독 수나 주일 설정을 바꾸면 하루 분량이 다시 나뉘고, **체크한 날짜 기록은 그대로 남습니다**(날짜 기준 저장).
- 공부량 조정도 같은 저장 방식(날짜 기준)을 써서, 조정 기록이 있어도 회독 수·주일 설정을 바꾸면 자동으로 해제됩니다.

### 오늘 공부량 미세 조정

- 오늘의 공부 카드 아래 **`공부량 조정`**과 **`완료`** 두 버튼이 나란히 있습니다.
  - `완료` — 오늘 분량을 통째로 완료 처리합니다(기존과 같음).
  - `공부량 조정` — 오늘 할당된 문항 번호가 **성경읽기표처럼 번호 칸**으로 뜹니다. 실제로 푼 번호만 콕콕 눌러 고르고(전체 선택/해제도 가능) `완료`를 누르면, **고른 문항만 오늘 완료**로 기록되고 **안 푼 문항은 다음 학습일부터 남은 일수·회독 수에 맞춰 다시 나뉩니다.**
- 예: 5회독 · 창세기 041~079(39문항) 중 41~60만 풀었다면 20문항을 체크하고 완료 → 11/24는 20문항 완료, 남은 19문항은 다음 날 분량에 자연스럽게 더해집니다.
- 지금까지 완료한 날의 기록은 그대로 남고, 전체 문항 수(회독별 3,006문항)도 줄지 않습니다. 같은 날 다시 `공부량 조정`으로 고쳐도 중복 없이 다시 계산됩니다.
- 조정한 계획은 기기에 저장되며, **더보기 → 원래대로 되돌리기**로 조정 전으로 돌아갈 수 있습니다.

### 진도가 밀렸을 때 — 오늘부터 다시 맞추기

- **오늘(오늘 이미 끝냈다면 그다음 미완료 날)부터 마감일 2027.11.30까지** 남은 학습일에, **남은 전체 회독 분량**(설정한 1~10회독 전체에서 아직 못 한 문항 + 밀린 날 분량)을 회독 순서대로 고르게 다시 나눕니다.
- **완료한 날의 체크 기록은 지우지 않고 그대로 둡니다.** 다시 맞추기 전에 못 한 지난 날은 `–`(넘어감)으로 표시되고 그 분량은 앞 날들로 옮겨 담깁니다.
- 다시 맞춘 계획은 기기에 저장되어 앱을 다시 열어도 유지되고, **더보기 → 원래대로 되돌리기**로 언제든 원래 일정으로 돌아갈 수 있습니다(되돌리면 밀린 날도 다시 `미완료`로 돌아옵니다).
- 회독 수나 주일 설정을 바꾸면 다시 맞추기는 자동으로 해제됩니다.

## 배포

GitHub Pages의 `main` 브랜치 루트를 그대로 배포합니다(빌드 과정 없음).
파일을 고쳐 올리면 앱을 열 때 새 버전을 받아 갑니다(오프라인 캐시는 `sw.js`에서 갱신).
계획 데이터를 바꾸려면 `schedule.js`의 권별 문항 수를 수정하면 됩니다.

아이콘을 바꾸면 `index.html`·`manifest.webmanifest`의 아이콘 주소 뒤 숫자(`?v=2` → `?v=3`)를 올려
캐시를 피하고, `sw.js`의 `CACHE` 이름도 함께 올립니다.
**아이폰에서는 이미 홈 화면에 추가한 앱의 아이콘이 자동으로 바뀌지 않습니다** — 홈 화면에서 그 아이콘을 길게 눌러
`앱 삭제`(또는 `홈 화면에서 제거`)한 뒤 Safari로 앱을 다시 열고 공유 → `홈 화면에 추가`를 해야 새 아이콘이 나옵니다.
홈 화면 앱을 지우면 그 앱의 저장 공간도 함께 지워질 수 있으니, 지우기 전에 앱의 `더보기 → JSON으로 내보내기(백업)`으로 체크 기록을 파일로 받아 두고, 다시 추가한 뒤 `JSON 불러오기(복원)`으로 되살립니다.
