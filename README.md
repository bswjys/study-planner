# 장신대 플래너

장신대 신학대학원 입학고사(2028학년도 대비)를 준비하는 **1~10회독 공부 계획 · 진도 관리** 웹앱입니다.
아이폰 사파리에서 열고 **홈 화면에 추가**하면 주소창 없는 단독 앱처럼 쓸 수 있어요.

## 쓰는 법 (아이폰)

1. 사파리에서 이 페이지를 엽니다 → https://bswjys.github.io/study-planner/
2. 하단 가운데 **공유** 버튼(□↑)을 누릅니다.
3. **홈 화면에 추가**를 선택합니다.
4. 홈 화면의 **장신대 플래너** 아이콘으로 실행하면 앱처럼 열립니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| **오늘** | D-day, 전체·현재 회독·이번 주 진행률, 오늘 분량 원터치 완료, 이번 주 7일 현황 |
| **회독** | 목표 회독(1~10) 선택, 회독별 기간·진행률, 날짜별/권별 전체 일정 탐색과 체크 |
| **캘린더** | 월별 달력, 주일(일요일) 휴식 표시, 완료/미완료/오늘/예정 색 구분, 날짜 탭 → 그날 공부 |
| **더보기** | JSON 백업·복원, 전체 초기화, 확장 탭 자리(논술 공부·운동 루틴), 학습 정보 |

- 체크는 누르는 즉시 진행률에 반영되고, **이 기기 브라우저(localStorage)에만** 저장됩니다. 서버로 보내지 않습니다.
- 기기를 바꿀 때는 더보기 → **JSON으로 내보내기**로 백업하고, 새 기기에서 **JSON 불러오기**로 복원하세요.

## 계획 계산 방식

- 공부 기간: **2026.11.23(월) ~ 2027.11.30(화)**, 주일(일요일) 제외 **320일**
- 범위: **66권(구약 39 · 신약 27) 3,009문항** — 삭제 3문항(요한복음 071 · 사도행전 045 · 로마서 031)은 범위에 두되 학습량에서 제외(실제 3,006문항)
- 목표 회독 `N`(기본 3)에 따라 320일을 `N`개 회독으로 나누고, 각 회독에서 66권을 번호 순서대로 배분합니다.
  - 3회독: 회독당 107 / 107 / 106일, 하루 약 28문항 (하루 26~30문항)
  - 10회독: 회독당 32일, 하루 약 94문항 (하루 92~95문항)
  - 1회독: 320일, 하루 약 9문항
- 하루 경계는 책 경계에 가깝게(±3문항) 맞춰 `레위기 001~001` 같은 자투리가 생기지 않게 했습니다.
- 회독 수를 바꾸면 하루 분량이 다시 나뉘고, **체크한 날짜 기록은 그대로 남습니다**(날짜 기준 저장).

## 배포

GitHub Pages의 `main` 브랜치 루트를 그대로 배포합니다(빌드 과정 없음).
파일을 고쳐 올리면 앱을 열 때 새 버전을 받아 갑니다(오프라인 캐시는 `sw.js`에서 갱신).
계획 데이터를 바꾸려면 `schedule.js`의 권별 문항 수를 수정하면 됩니다.
